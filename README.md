# 今日好运补给

在线打开：[今日好运补给](https://cyrus-svg.github.io/little-luck/)

一个无需安装的小互动页面：摸摸兔头、收集三颗星星、换帽子、乘小飞船，再翻翻今日小纸条。

- 入口为 `index.html`，电脑和手机浏览器均可打开。
- 页面中的编辑按钮可修改称呼与第一张纸条；支持下载带有自定义内容的独立 HTML。
- 默认静音，音乐可手动开启；支持键盘操作和系统「减少动态效果」。
- 所有互动在浏览器本地运行，不需要外部脚本、字体或后端服务。

这是用于 GitHub Pages 的纯静态发布目录；`.nojekyll` 禁用 Jekyll，`cover.png` 用作链接预览封面。页面图标为内嵌 SVG。
